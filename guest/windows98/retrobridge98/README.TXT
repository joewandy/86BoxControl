RETROBRIDGE98
=============

1. Start the RetroBridge service on the native Windows or macOS host.
2. Run INSTALL.VBS to install the browser and its pairing configuration.
   RB98.EXE and RB98.INI are 8.3-safe copies used by the installer on Win98.
3. Open the RetroBridge98 shortcut.

Setup asks whether RetroBridge98 should start with Windows and defaults to No.
Use the Start menu shortcuts to enable or disable startup later. Uninstall also
removes the Startup shortcut.

Close RetroBridge98 before installing an upgrade. Setup will explain this if
Windows has locked the running program file.

Type a public web address and press Enter. Press F6 to select the address,
F5 to reload, Esc to stop, Ctrl+F to find text, and Alt+Left or Alt+Right to
move through history. Use the rendered scrollbar, mouse wheel, Page Up, or
Page Down to move through long pages. The menus also provide Home, Favorites, local clipboard
commands, a host-side download inbox, and connection diagnostics.

Favorites can be opened, renamed, deleted, and reordered from Manage Favorites.
Home mirrors safe Favorites and shows guest/renderer versions and recent
downloads. File > Download History shows the bounded history stored on the host.

Downloads are stored in the host user's RetroBridge98 download inbox and are
never opened automatically. Chromium uses a temporary native-host profile. This release has no
uploads, audio, printing, tabs, saved cookies, or saved passwords. Do not enter
sensitive credentials into pages displayed by an unpatched vintage operating
system.
